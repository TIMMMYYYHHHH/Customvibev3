## Existing template: one plain-paper calibration check

- [ ] **C1 Print settings:** use the same printer/application you normally use. Select A4, portrait, Actual size/100%, with Fit/Shrink to page disabled. Give the printer and application names. This is a paper-only template measurement, not production acceptance.
- [ ] **C2 Ruler measurement:** measure one outer octagon across its full width and height and one of the regular square landscape frames. Digital dimensions are approximately 87.20 x 86.19 mm for the outer outline and 67.00 mm for a regular image frame; top-left differs at about 64.65 mm. Record measured values instead of changing the website to fit a guessed size.
- [ ] **C3 Fold relationship:** the finished face is confirmed at 63.5 x 63.5 mm and the octagons are fold guides. Show one non-personal example before folding and after finishing, or explain where the image edge lies relative to the face/fold. This establishes the required image bleed without guessing from the PDF's 67 mm frames. Do not reuse the older generic 75 mm sample as the production template.

## Admin print action: test after it is built

- [ ] **A1 Placement:** six clearly different synthetic images occupy the correct approved positions and order; no landscape placeholders, old order images or reference previews remain. If the approved layout uses a different number of positions, use that number instead.
- [ ] **A2 Quantities and pagination:** for a six-slot layout, A x 3 + B x 2 + C x 2 produces seven magnets over two pages, with exactly one populated slot on the second page. Totals match the order; empty slots stay empty.
- [ ] **A3 Puzzles:** two 3 x 3 sets produce 18 tile placements over three six-slot pages. Each of the nine tile positions appears twice, in the agreed arrangement. The large assembled reference is not a print tile. Check a 5 x 5 job digitally as well; a 25-tile set needs five six-slot pages, not one image.
- [ ] **A4 Exact artwork:** compare representative saved order images with the generated PDF. Crop, orientation, editable wording and QR destination match. Do not treat a layout control as permission to recrop or stretch the customer's design.
- [ ] **A5 Calibration:** print one plain-paper sample, measure the 63.5 x 63.5 mm face, adjust X/Y or spacing in Admin and print again. Check every position, including the last row. The guide/image relationship and physical size must remain correct. If printer profiles are included, test remember, new-tab use and reset for that same printer.
- [ ] **A6 Real material:** after paper calibration passes, print/finish one actual magnet sample and one puzzle set with the normal production process. Inspect cuts/folds, readability, colour, joins and QR scanning. Record the material/finish. A paper-only pass does not establish finished-product quality.
- [ ] **A7 Safe failures and unchanged workflow:** missing/expired artwork or a changed revision is explained and does not produce a silently incomplete job. Preparing a sheet does not send email, change an order stage or imply payment. Local fixture testing must not create/edit a real customer order to manufacture this case.
